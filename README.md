# THE QUIET VAULT

Unity 6000.6.2f1製の、3D見下ろし型ダンジョン探索ゲームです。猫を操作して、ネズミと罠のある部屋を探索します。
罠にはKenneyの既存3Dアセット「Platformer Kit 4.1」（CC0）を使用しています。出典と利用条件は `THIRD_PARTY_NOTICES.md` に記録しています。

プレイヤーは白とグレーのローポリ猫です。翡翠色のスカーフと小さな金色のチャームを身に付け、歩くと四足が動き、しっぽが揺れます。
猫のモデルはこのゲーム用に作成したオリジナルです。外部の罠モデルもプロジェクトに同梱済みです。

## 罠

既存の3Dモデルを使用した3種類の罠があります。接触時は1ダメージで、敵の攻撃と同じ1秒の被弾後無敵時間が適用されます。

| 種類 | 動作 |
| --- | --- |
| 床トゲ | 収納 → 黄色い予告 → トゲが伸びる、を4.5秒周期で繰り返す。収納中と予告中は安全 |
| 丸ノコ | 回転しながら左右または前後に往復し、刃に触れるとダメージ |
| トゲ付きブロック | 動かない接触罠。触れるとダメージ |

通常の開始部屋は罠なしです。罠の候補数は初級0〜1、中級0〜2、上級0〜3個で、抽選率も45%／65%／80%と増えます。さらに開始部屋以外の1部屋を罠なしにします。
入り口・部屋中央・ネズミの初期位置を避け、中央を通って各扉へ進む経路は常に安全です。安全に置けない候補は省きます。
罠は猫にダメージを与えます。ネズミには罠ダメージはありません。
別の部屋・メニュー・クリア後・ゲームオーバー後では罠は停止します。再入室では作動状態を保持し、再挑戦では配置と初期周期に戻ります。
罠でHPが0になった場合もゲームオーバーになります。

## ネズミ

探索開始時に、部屋ごとのネズミの数・種類・初期位置・向きをランダムに決めます。
逃走型だけ、攻撃型だけ、混在、ネズミなしの部屋があります。

| 難易度 | 出現数 | 数の抽選比率（0匹から順） | 1匹ごとの攻撃型の確率 |
| --- | --- | --- | --- |
| 初級 | 0〜2匹 | 40% / 40% / 20% | 20% |
| 中級 | 0〜3匹 | 25% / 25% / 30% / 20% | 45% |
| 上級 | 0〜4匹 | 15% / 15% / 25% / 25% / 20% | 70% |

スタートは必ず空室です。さらにスタート以外からランダムに1部屋を空室にするため、実際の空室率は表の0匹の抽選率より少し高くなります。
出現位置は入り口と部屋中央を避け、ネズミ同士も重ならないように決めます。
再入室では抽選し直さず、移動後の位置・撃破状態を保持します。同じ地図で再挑戦すると、敵の数・種類・位置も最初の配置に戻ります。
難易度選択から新しい探索を始めると、地図と敵配置の両方を生成し直します。

### 茶色のネズミ（逃走型）

茶色い体、丸い耳、ピンク色の長いしっぽが目印です。
約4.5ユニット以内の視野（前方240度）にいる猫に気づくと「！」を出して逃げます。すぐ近く（1.4ユニット以内）では背後からも気づきます。
逃走速度は3.25ユニット／秒で、猫の最大速度4.4ユニット／秒より遅めです。壁や角を避けて同じ部屋の中で逃げ、猫を見失って1.4秒たつと落ち着きます。
ネズミの位置は部屋を出入りしても保持されます。難易度選択中・クリア後・別の部屋にいる間は停止し、やり直すと初期配置に戻ります。
猫パンチを当てると一撃で倒せます。倒されたネズミは跳ねて小さくなり、消えます。
撃破状態は部屋を出入りしても保持され、やり直し／新しい探索で復活します。倒した数は画面左上に表示します。

### 赤色のネズミ（攻撃型）

赤い体と背中の赤い印が目印です。6ユニット以内の猫に気づくと、逃げずに速度2.6ユニット／秒で追いかけます。
猫の近くでは立ち止まり、大きく点滅する「！」と体を構える動きの後、0.45秒で攻撃します。
攻撃時に1.05ユニット以内にいる猫へ1ダメージを与えます。構えている間に離れると回避できます。
攻撃後は1.2秒の待ち時間があります。猫パンチで倒すと、構え中の攻撃も止まります。

## HPとゲームオーバー

猫の最大HPは5で、画面右側に残量を表示します。被弾1回で1減り、被弾後1秒間は点滅して追加ダメージを受けません。
HPは部屋を移動しても保持されます。0になるとゲームオーバーとなり、移動・攻撃・ネズミの行動が停止します。

- 同じ地図で再挑戦：R／Enter／Space、パッドY／A、または画面のボタン
- 難易度選択に戻る：N、パッドStart／B、または画面のボタン

再挑戦ではHP、敵、探索記録をリセットします。難易度選択中・クリア後・ゲームオーバー後にはダメージを受けません。
ゴール到達と致死ダメージが同時に発生した場合はゲームオーバーを優先します。

## 猫パンチ

- キーボード：Space または J
- ゲームパッド：X（Xbox表記。右側4ボタンの左）

猫の向いている方向の前方120度、距離1.3ユニット以内にいるネズミに当たります。
移動しながら攻撃すると、その移動方向を向いてパンチします。空振りも可能です。
ボタンを押すたびに1回攻撃し、次のパンチまでは0.38秒必要です。長押しでは連打しません。
難易度選択中・クリア後・ゲームオーバー後は攻撃せず、Spaceはメニューの決定／再挑戦操作になります。

## 起動

`Builds/Windows/QuietVault.exe` を開きます。配布時はWindowsフォルダー全体を渡してください。

- WASD / 矢印キー：移動。光る扉の先まで歩くと隣の部屋へ移動します。
- 起動時に初級・中級・上級をクリック、または1 / 2 / 3キーで選択
- R：同じ地図でスタートからやり直す（探索記録もリセット）
- N：難易度選択に戻り、新しい地図で探索する
- Esc：終了

## ゲームパッド

WindowsのXInput対応パッド（Xbox系・互換パッドなど）で遊べます。切替式の製品はXInputモードを使用してください。
Unity Input SystemがGamepadとして認識する機器を対象にしています。独自配列のDirectInput専用機器は対象外です。
キーボード・マウス操作も引き続き使用でき、操作モードを切り替える必要はありません。

| 操作 | パッド（Xbox表記） |
| --- | --- |
| 移動 | 左スティック／方向キー |
| 難易度選択 | 左右 |
| 決定／クリア後の新しい探索 | A（右側4ボタンの下） |
| 猫パンチ | X（左） |
| 同じ地図でやり直す | Y（上） |
| 難易度選択に戻る | Start／B（右） |
| 難易度選択画面で終了 | B（右） |

スティックは倒す量で速度を調整できます。中心付近にはデッドゾーンを設け、斜め移動の速度も制限しています。
接続・切断は起動中でも反映します。キーボードで方向を入力している間はキーボードを優先します。
難易度選択ではキーボードの左右＋Enter／Spaceも使用できます。従来の1／2／3キーも有効です。

難易度を選ぶたびにランダムなダンジョンを生成します。

| 難易度 | 部屋数 | スタートからゴールまでの最短移動回数 |
| --- | --- | --- |
| 初級 | 12 | 5回以上 |
| 中級 | 24 | 8回以上 |
| 上級 | 42 | 12回以上 |

全室は上下左右で双方向につながり、戻る方向を含めて最大4方向に進めます。
ゴールはスタートから最も遠い部屋です。
右上の地図はスタートの1部屋から始まり、訪れた部屋だけが追加されます。
訪問済みの部屋から見える通路は短い線、訪問済み同士の通路はつながった線で表示します。
未訪問の部屋・通路同士のつながり・ゴール位置は表示しません。縮尺も発見済みの範囲だけで調整します。
Sがスタート、現在地は明るい緑。Gはゴールの部屋へ実際に入った時点で表示されます。
ゴール部屋の中央にある金色のクリスタルまで歩けばクリアです。
すべての部屋を探索する必要はありません。記録は起動中のみ保持します。

## 編集とビルド

Unity Hubにこのフォルダーを追加し、`Assets/Scenes/Dungeon.unity`を開いてPlay。
`Assets/Scripts/DungeonGame.cs` が部屋配置・移動・3D表示・UIを担当します。
`Assets/Scripts/DungeonLayout.cs` がランダムな部屋配置と探索記録を管理します。
`Assets/Scripts/DungeonInput.cs` がキーボードとゲームパッドの入力をまとめます。
`Assets/Scripts/CatPunch.cs` が攻撃範囲・方向・再攻撃間隔を管理します。
`Assets/Scripts/CatHealth.cs` がHP・被弾後の無敵時間を管理します。
`Assets/Scripts/RoomEncounters.cs` が難易度ごとの出現率と、再現可能な敵配置の抽選を担当します。
`Assets/Scripts/RoomTraps.cs` が罠の配置・周期・当たり判定、`TrapActor.cs` が既存モデルの表示を担当します。
罠の原本は `Assets/ThirdParty/KenneyPlatformer/`、ゲーム用Prefabは `Assets/Resources/Traps/` です。**Dungeon > Import Trap Prefabs** またはビルドでPrefabを再作成できます。
`Assets/Scripts/RatBrain.cs` がネズミの視認と逃走、`RatActor.cs` が3Dモデルとアニメーションを担当します。猫のオリジナルメッシュを共有しています。
猫のモデルは `Assets/Resources/ExplorerCat.prefab`、メッシュとマテリアルは `Assets/Resources/CatModel/` にあります。
`Assets/Scripts/CatAvatar.cs` が猫の形状定義と歩行・待機アニメーションを担当します。
Unityメニューの **Dungeon > Rebuild Cat Model** でモデルを再生成できます。ビルド時にも再生成するため、恒久的な形状変更は `CatAvatar.cs` に反映してください。
Input System 1.20.0を使用し、Active Input HandlingはBoth（従来の入力も有効）にしています。
部屋配置は上下左右で隣接する座標同士が双方向につながり、未訪問の部屋の情報は地図描画に渡しません。
Unityメニューの **Dungeon > Build Windows** または `Build-Windows.ps1` で再ビルドできます。

## 検証

実行ファイルに `-batchmode -nographics -selftest -logFile <ログパス>` を渡すと、
各難易度200通り、計600通りの地図で部屋数・全室への到達性・最大4方向・帰り道・ゴール距離・ランダム性を検証します。
敵配置も各難易度200通りで、空室保証・数と種類の分布・出現位置の安全性・重なり防止・同じ乱数種での再現性を検証します。実際のゲーム状態で再入室時の位置／撃破状態の保持と、再挑戦時の初期配置復元も確認します。
さらに初期表示・未訪問の通路とゴールの非表示・到達時の開示・壁・扉の通過・ゴール判定・リスタート・難易度選択を検証します。
成功時は終了コード0、失敗時は1です。
罠は300通りの地図で安全な通路・配置・再現性を検証し、全3種のモデル読込・ダメージ・無敵時間・周期・停止・再挑戦・ゲームオーバーも検証します。
表示確認用に実行ファイルへ `-trap-preview` を渡すと、同じPrefabとダメージ処理を使う3種類の罠の確認部屋を開けます。通常起動の地図生成には影響しません。
ネズミの視野・接近検知・逃走・落ち着く動作・猫との重なり・壁と四隅の回避・部屋ごとの位置保持・停止・リスタートも検証します。
猫パンチの方向と距離、空振り、連続攻撃の間隔、二重撃破の防止、撃破状態の保持とリセット、メニュー／クリア後の攻撃禁止、仮想パッドのXボタン入力も検証します。
攻撃型の追跡・予備動作・回避・攻撃間隔、HP減少・無敵時間・下限、部屋移動時のHP保持、ゲームオーバー中の停止、再挑戦、倒した敵の攻撃中断、ゴールと致死ダメージの優先順位も検証します。
仮想Gamepadの入力イベントでスティック・方向キー・決定等のボタン・デッドゾーン・切断／再接続・長押しを検証し、キーボードとの併用とゲーム内のメニュー遷移も検証します。実物のゲームパッドによる手動確認は未実施です。

## ローカル変更履歴

このフォルダーをGitリポジトリとして管理しています。まとまった変更と必要な検証が完了するたびにコミットします。作業ルールは `AGENTS.md` に記載しています。

- 履歴を確認：`git log --oneline`
- 変更内容を確認：`git show <コミットID>`
- 過去の状態を別フォルダーで開く：`git worktree add --detach ../DungeonExplorer3D-review <コミットID>`

過去の状態を開いた後は、そのフォルダーの `Build-Windows.ps1` で実行ファイルを再作成できます。
最初の保存対象は、全12部屋・部屋間の往復移動・探索マップ・ゴール判定・リスタートが実装された試作版です。それ以前の状態は履歴に含まれません。
ソースと設定をローカルに保存し、Unityのキャッシュやビルド成果物は除外します。リモートへの送信は行いません。
