猫パンチとひみつの迷宮
Windows 64ビット版

■ 起動方法
ZIPをすべて展開し、NekoDungeon.exeを開いてください。
実行ファイルと同じ場所のデータフォルダー、DLLなども必要です。
Unity Editorのインストールは不要です。

■ 遊び方
猫を操作して部屋を探索し、金色のクリスタルがある出口を目指します。
茶色いネズミは逃げ、赤いネズミは攻撃します。猫パンチで倒せます。
床トゲ・丸ノコ・トゲ付きブロックに注意。HPが0になるとゲームオーバーです。
地図は探索に合わせて広がります。初級・中級・上級を選べます。

■ キーボード
WASD / 矢印キー：移動
Space / J：猫パンチ
R：同じ地図で再挑戦
N：難易度選択
Enter / Space：メニュー決定
Esc：終了

■ ゲームパッド（Xbox / XInput表記）
左スティック / 方向キー：移動・選択
A：決定　X：猫パンチ　Y：再挑戦
Start / B：難易度選択（選択画面のBは終了）
